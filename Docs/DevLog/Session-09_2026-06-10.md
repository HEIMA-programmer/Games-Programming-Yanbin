## 2. What changed since last session

- **PatrolDrone overhaul** (`PatrolDrone.cs` + prefab):
  - The hard cone sprite is replaced by a **volumetric `Light2D` searchlight** (60° soft
    beam; volumetric intensity enabled — a 2D light is *invisible* over empty black without
    it). **Brightness is the state language**: dim sweep (0.8) → blazing alert (2.2) → near
    dark when stunned (0.05), with the body sprite dimmed to 45 % while disabled.
  - **Clone contact actually fires now**: the contact collider was already a trigger, but
    the drone's kinematic body had `useFullKinematicContacts` off — and Unity raises no
    trigger events between kinematic pairs, so the (also kinematic) echo clone could never
    actually be "eaten" by touch. It's now forced on (prefab + `Awake`), with `isTrigger`
    forced too as belt-and-braces for any stray instance.
  - **Stunned drones are harmless to touch** — eating a decoy powers the body down, and the
    player escapes *through* the sleeping sentry. This is what makes the decoy-stun loop
    solvable on flat ground.
  - **Unified gaze-alarm**: every drone's line of sight now feeds the detection meter
    (fill → checkpoint respawn) — `detects` is on by default in the prefab; chasers differ
    from sentinels **only in whether they pursue**. Leash-0 sentinels now pin and *stare*
    at their zone edge instead of breaking off to walk home (walking home faced away and
    reset the meter every sweep, making gaze zones toothless).
- **Level 2 = SECTOR 02 — HIDE AND SEEK** (was "Deep Labs"), a ~56u five-segment

## 3. Decisions & how my thinking changed

- **Decision:** the beam is a **light, not a sprite**, and **brightness is the entire
  state language**. **Why:** Session 02's cone was an *iconographic* warning; over a pure
  black world a volumetric beam is a *spatial* one — you read where is lit, not what
  colour a triangle is. It also collapses three colour states into one dimension
  (intensity), which is the 1-Bit rule from Session 04 applied to the enemy.
  **Honesty note:** the visible beam (60°, 4.9u) is slightly *generous* versus the actual
  detection test (52°, 4.5u) — the safe margin errs in the player's favour on purpose.
- **Decision:** **one detection model everywhere** — the per-level special case from
  Session 02 ("stealth meter only on L3 corridor drones") is gone; every drone's gaze
  feeds the meter, and the *only* axis of variation is pursue-or-pin (leash).
  **Why:** L2 is now *the* stealth level, and a rule the player learns must not silently
  vary by room. Sentinels-that-stare came out of this: a leash-0 drone that walks home
  after every glance can't hold a zone.
- **Decision:** the step-stool wall sits in a **drone-free safe pocket**.
  **Why:** it's a *teaching* gate for a verb most players haven't used (Playtest 03). New
  verb under pressure = frustration; new verb in safety, then *used* under pressure later
  if the player chooses — that's the L0 echo-gate philosophy reapplied.
- **Decision (scope):** fewer drones, fewer fragments, more structure — consistent with
  the "refinement over scale" principle this project runs on. A five-segment composite
  with three drones examines more of the game than the old four-area layout did with five.
- **Honesty note (what this session did *not* invent):** the standable echo is Session
  03's mechanic; the detection meter dates back to Session 02's `ReportSeen()` plumbing.
  This session's contribution is the *defaults flip*, the leash-0 stare fix, and the level
  that makes both load-bearing.

## 4. Problems hit & how I solved them

- **Drone contact never triggered against echo clones.** *Cause:* both the drone and the
  clone are kinematic `Rigidbody2D`s with `useFullKinematicContacts` off — Unity raises no
  trigger events for kinematic-kinematic pairs, so the collider (already a trigger) stayed
  silent against clones; only the dynamic player registered. *Fix:* force
  `useFullKinematicContacts = true` (and `isTrigger = true` as belt-and-braces) in `Awake`,
  so old scene instances heal themselves.
- **Leash-0 sentinels broke off the chase instantly.** *Cause:* `BeyondLeash()` is
  trivially true at distance 0, so the sentinel entered Return on the first chase tick —
  facing away, resetting the meter. *Fix:* the leash break only applies when `leash > 0`;
  zero-leash drones pin at the zone edge and keep staring/reporting.
- **Touching a stunned drone still killed you.** *Cause:* the contact handler didn't check
  state — which made segment 3 unsolvable, since the decoy-stun escape requires passing
  through the sleeping body. *Fix:* early return when stunned.
