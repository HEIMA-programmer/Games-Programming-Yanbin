# Playtest 02 — 2026-05-27

**Build / version:** v0.4 → v0.5 (Session 02, end of Wed evening)
**Levels tested:** Level_02 + Level_03 (the AI rewrite landed here) plus a full L0 → L3 regression run.
**Tester:** self (developer). The fresh-player round is still owed and will happen before Session 03 — see "Still open" below.
**Setup:** Unity 2022.3 editor Play mode, keyboard.

## Goal of this round

The big change of the week is that the patrol drone is no longer a back-and-forth hazard
that hurts on contact — it has a real line-of-sight sense, a chase state machine, and a
stealth-detection rule on the L3 corridor. I needed to answer four things before calling
Session 02 done:

1. **Does the cone actually act as a sense?** Cover should break sight; range should match
   what the cone sprite shows; the drone should alert, chase, search, and walk home rather
   than glue to me.
2. **Is the echo a *meaningful* decoy now?** Clone-first targeting + chase slower than the
   player should mean a recorded clone reliably draws the drones off my lane.
3. **Can chase or stealth detection ever trap me?** No off-level chases, no corner softlocks,
   no permanent locks like the old L3 mirror-room gate.
4. **Did the Section-B polish actually land cleanly?** Death juice readable, plate particle
   visible, audio fuller without clipping, font crisp at every UI surface, no new git churn.

## Tasks performed

1. Replayed all of L2 (drone intro → echo decoy → timed run → two-enemy gauntlet) checking
   the new chase/leash behaviour. L2 drones run with `detects: false`, so contact-only
   behaviour must be preserved.
2. Replayed all of L3 in three modes:
   - Area 2 with the old mirror-room flow attempted (try to lock myself behind the removed gate).
   - Area 3 stealth corridor solved with **cover + timing only** (no recording).
   - Area 3 stealth corridor solved with **a recorded clone as decoy**.
3. Held a drone's gaze on purpose in L3 corridor to confirm the meter, the screen-redden
   warning, and the respawn at the area checkpoint.
4. Stress-tested the chase: ran straight past every drone's patrol edge to confirm the
   leash kicks in and the drone returns rather than following me off the level.
5. Triggered death repeatedly in L2/L3 to evaluate the hit-stop + camera shake — both for
   read and for "does this drag after 10 deaths."
6. Pressed every pressure plate in the game (player and clone) to confirm the press
   particle reads on press and not on release.
7. After Build All, ran `git status` to confirm `.wav` files and the font `.asset` were no
   longer dirty just from playing.
8. Looked at every UI surface (main menu / level select / HUD / pause / victory / world
   narrative) to confirm Exo 2 renders with no overflow and no missing glyphs (boxes).
9. Full L0 → L3 regression playthrough to make sure none of the above broke an earlier
   level (Session 01 verified L0–L3 end-to-end; that needed to still be true).

## What I changed because of this

- **Obs #1** → removed the L3 mirror-room door + its one-way gate entirely; that area is
  now an optional Echo-Lift (clone holds plate, ride the platform up, jump for the
  fragment). Commit `610ad84` (PR #5).
- **Obs #2** → rebuilt L3 area 3 as a real cover-based stealth corridor: two cover pillars
  block LoS, both drones run with `detects: true`, a world-space sign teaches *"hide, time
  it, or send a decoy."* Commit `610ad84` (PR #5).
- **Obs #3** → tightened the L2 upper-gauntlet drone's leash to `4` so it can't chase off
  the ledge edge. Commit `610ad84` (PR #5).
- **Obs #4** → regenerated the cone sprite in `EchoArt` to match `viewRange` × half-angle.
  Commit `610ad84` (PR #5).
- **Obs #5** → moved the meter integration into `GameManager.FixedUpdate` and drove it
  from `PatrolDrone.FixedUpdate` calling `ReportSeen()`, so the increment uses
  `Time.fixedDeltaTime` on the same step as the LoS check. Commit `610ad84` (PR #5).
- **Obs #6** → `RespawnRoutine` now does a 0.09s hit-stop (`Time.timeScale = 0.12f`) plus
  a 0.55-amplitude `CameraShake.Shake`, both running on unscaled time. Commit `707b492`
  (PR #6).
- **Obs #7** → `EchoAudio.GenerateAll` seeds `Random.InitState(82914)` at the top, so the
  generated WAVs are byte-identical on every Build All. Commit `707b492` (PR #6).
- **Obs #8** → `EchoFont` now pre-bakes the glyph set the UI actually uses and forces
  `atlasPopulationMode = Static`, with an auto-heal for an existing Dynamic asset. Commit
  `2d74648` (PR #7).
- **Obs #9** → `PressurePlate.Refresh` only emits when the plate transitions to pressed,
  not on release. Commit `707b492` (PR #6).
- **Obs #10** → `EchoAudio` thickened: layered sub + body + attack on Land, a fifth-up
  partial on Jump, a slow pad / shimmer layer on both BGM tracks. Commit `707b492` (PR #6).
