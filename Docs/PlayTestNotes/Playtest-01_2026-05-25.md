# Playtest 01 — 2026-05-25

**Build / version:** v0.1 → v0.3 (Day 1)  **Levels tested:** Level_00 – Level_03
**Tester:** self (developer)  **Setup:** Unity 2022.3 editor Play mode, keyboard

## Goal of this round

After building each milestone I played the whole game to answer three questions:

1. Does the core loop (record → clone → plate → door) actually work inside a real level?
2. Are the enemy sections solvable *only* with the clone-as-decoy, or can they be cheesed?
3. Can the player get stuck, crushed, or blocked anywhere?

## Tasks performed

1. Played Level_01 areas 1–5 end to end.
2. Played Level_02 (drone intro → echo decoy → timed run → two-enemy gauntlet).
3. Played Level_03 (rising-platform gauntlet → mirror room → decoy corridor → memory core).
4. Deliberately tried to *break* each section: skip the decoy, over/under-jump the ledges,
   and re-run the level builder.

## Observations

| # | Where | What happened | Severity |
| - | ----- | ------------- | -------- |
| 1 | All menus / HUD | Buttons did nothing — code-built canvases had no `EventSystem` | High |
| 2 | L3 areas 1 & 2 | The rising platform pushed me into the walkway above and pinned me | High |
| 3 | L2 A2 / L3 A3 | I could run past the drones without a clone, so the decoy felt pointless | Med |
| 4 | Optional fragments | A couple of fragment ledges sat above my jump height | Med |
| 5 | Build pipeline | Running the builder twice produced duplicate objects | Med |

## What I changed because of this

- **Obs #1** → builders now add one `EventSystem` per scene → menus are clickable (PR #2).
- **Obs #2** → offset the walkways so the platform stops flush with the ledge instead of
  rising through it (PR #3).
- **Obs #3** → tightened patrol distance/speed and added a safe record buffer at each
  corridor entrance, so the clone decoy is genuinely required (PR #3).
- **Obs #4** → lowered the optional fragment ledges to within jump range (~2.8 units) (PR #3).
- **Obs #5** → made the build idempotent: it clears the previous output and rebuilds (PR #1).

## Resolved after this round

- **Softlock check:** verified — no drone patrol overlaps a required plate or the only path.
  Level 2 Area 4 is clear (the upper drone clears the plate at x88; the bridge drone never
  blocks the route). No change needed.
- **Timed run:** verified — the 5-second clone is long enough to sprint plate → door past
  the patrol in Level 2 Area 3. No change needed.
