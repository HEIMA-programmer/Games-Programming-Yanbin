# Echo Shift

A 2D puzzle-platformer where you **record your own movements and replay them as a ghost
clone** — cooperating with yourself to solve puzzles that need two bodies.

![Echo Shift main menu](../Docs/DevLog/screenshots/menu.png)

## The idea

You play a lone machine waking up in an abandoned lab. Your one ability: hold **R** to
record up to five seconds of movement, then release to spawn a glowing *echo* of yourself
that replays exactly what you just did. Use the echo to hold a pressure plate open, ride a
platform up, or act as a decoy that lures a patrolling drone — then run through while your
past self does the other half of the job.

Every room is a small loop: **observe → plan → record → act → solve.**

## Controls

| Action | Key |
| ------ | --- |
| Move | `A` / `D` (or `←` / `→`) |
| Jump | `Space` / `W` / `↑` (variable height — hold for higher) |
| Record echo | Hold `R` (up to 5s); release to spawn the clone |
| Pause | `Esc` |
| Menus | Mouse |

Only one echo exists at a time — starting a new recording dissolves the old one.

## How to run

The game targets **Unity 2022.3.62f3 (LTS)** with the Universal Render Pipeline. All
generated assets are committed, so it runs straight from a clone:

1. Open the `Echo_Shift_01` folder in Unity Hub (Unity 2022.3.62f3).
2. Open `Assets/_Scenes/MainMenu.unity`.
3. Press **Play**, then **Start Game** (or **Level Select**).

**Reproducing the assets from source (optional).** Every sprite, sound, prefab, and scene
is generated by editor scripts. To rebuild them from nothing, use the **`EchoShift`** menu
in the Unity menu bar → **`Build All`** (the first run may import TMP Essentials and ask for
one more click). To make a standalone build, use **File ▸ Build Settings ▸ Build**.

## Levels

| Scene | Name | Introduces |
| ----- | ---- | ---------- |
| `Level_00` | Awakening | Mood + movement only (no echo / enemies) |
| `Level_01` | Sector 01 | The record-and-replay mechanic; pressure plates + doors |
| `Level_02` | Sector 02 — Deep Labs | Patrol drones; the echo as a decoy; timed runs |
| `Level_03` | Sector 03 — The Core | Everything combined: mirror room, decoy corridor, ending |

About 5–8 minutes of play. Three memory fragments per level (9 total) reward exploration.

## Accessibility, legal & ethical notes

- **Input:** keyboard for play, mouse for menus. Movement and jump each accept multiple keys.
- **Feedback is paired:** important events have both a visual and an audio cue (recording
  vignette, hit flash, pressure-plate light, SFX), so no single channel is required.
- **No harsh strobing** — lighting is soft glow / bloom. Calm, untimed pacing outside the
  one optional timed section.
- **Privacy/security:** the game is fully offline and collects no data.
- **Assets:** all original (see Credits) — no third-party or licensed content is used.
