# Games Programming — Yanbin

Coursework repository for the Games Programming module.

## Main project: Aftertrace

A 2D puzzle-platformer where you record your movements and replay them as a ghost clone to
solve puzzles that need two bodies. See **[Aftertrace_01/README.md](Aftertrace_01/README.md)**
for the game, controls, and how to run it.
