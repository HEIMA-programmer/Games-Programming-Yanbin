# Games Programming — Yanbin

Coursework repository for the Games Programming module.

## Main project: Aftertrace

A 2D puzzle-platformer where you record your movements and replay them as a ghost clone to
solve puzzles that need two bodies — hold a plate, stand on your echo's head, replay a
crate push, or bait a searchlight drone. Three hand-authored levels and four illustrated
story acts, in a 1-Bit + cyan visual identity. See
**[Aftertrace_01/README.md](Aftertrace_01/README.md)** for the game, controls, and how to
run it.
